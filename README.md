## ⚡ Game Features
- **Poker Scoring Formula:** \`Score = Total Chips × Multiplier\`.
- **Full Poker Hands:** High Card, One Pair, Two Pair, Three of a Kind, Straight, Flush, Full House, Four of a Kind, Straight Flush, Royal Flush.
- **15+ Neon Jokers:** Equip up to 5 game-breaking Jokers with synergies (Polychrome, Scary Face, Bullseye, Suit Wrath, Baron King synergy, and more).
- **Planet Upgrades:** Level up hand types in the Neon Casino Black Market to permanently boost base chips and multiplier values.
- **8 Ante Progression:** Small Blind, Big Blind, and Boss Blinds with tactical boss modifiers (debuffed suits, restricted discards, elevated targets).
- **Procedural Web Audio Synthesizer:** Real-time card swooshes, selection clicks, pitch-ascending chip counts, bass multiplier hits, and victory arpeggios — zero external audio files.
- **Virality & Sharing:** 1-tap WhatsApp and social media score bragging (\`Pamer Rekor\`).
- **Responsive Controls:** Mobile touchscreen gestures and desktop mouse navigation.

## 🛠️ Tech Stack
- HTML5 Canvas & DOM Elements
- Web Audio API (real-time synthesizer)
- LocalStorage High Score System (\`neondeck_hs\`)
- Zero external runtime libraries
